# Shipment Operations SQL Analysis

## Project Objective
This project analyzes shipment and delivery operations using SQL to identify operational trends, shipment performance, delayed deliveries, and warehouse KPIs.

---

## Dataset Used
E-Commerce Shipping Dataset

The dataset contains:
- Shipment details
- Warehouse blocks
- Delivery performance
- Product importance
- Customer ratings
- Shipment modes

---

## Skills Demonstrated
- SQL Queries
- Data Analysis
- Aggregation Functions
- GROUP BY
- ORDER BY
- Filtering using WHERE
- KPI Analysis
- Business Insights

---

## SQL Business Questions Solved

### 1. Total Orders Analysis
Identified total shipment records in the dataset.

### 2. Delayed Delivery Analysis
Calculated number of delayed shipments.

### 3. Shipment Mode Performance
Analyzed which shipment mode handled most deliveries.

### 4. Warehouse Performance
Compared warehouse blocks based on total orders handled.

### 5. Customer Rating Analysis
Calculated average customer satisfaction rating.

### 6. Product Importance Analysis
Analyzed order distribution by product importance level.

---

## Tools Used
- SQL
- GitHub
- CSV Dataset

---

## Key Insights
- Certain warehouse blocks handled significantly more shipments.
- Delayed deliveries formed a major percentage of total orders.
- Shipment mode distribution was uneven across operations.
- Customer ratings highlighted delivery experience trends.
